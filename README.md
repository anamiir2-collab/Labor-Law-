# قانون العمل رقم ١٤ لسنة ٢٠٢٥ — موقع ثابت

موقع ويب ثابت بالكامل لعرض **قانون العمل المصري الجديد رقم ١٤ لسنة ٢٠٢٥** والقانون المرافق له، بتصميم أندلسي (الأخضر الزمردي، الذهبي، العاجي) وواجهة RTL متجاوبة بالكامل.

| المواد المرقمة (القانون المرافق) | ٢٩٨ مادة |
| **إجمالي المواد** | **٣١١ مادة** |

## الرفع على GitHub Pages (بدون أي إعدادات)

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملف **index.html** إلى جذر المستودع (Repository Root).
3. من **Settings → Pages** اختر: **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. خلال دقيقة سيصبح الموقع متاحًا على:
   `https://<username>.github.io/<repository-name>/`

> لا يوجد Build، لا npm، لا Node، لا Backend — الملف يعمل كما هو.

## المزايا

- ملف واحد مستقل تمامًا: كل الأنماط والسكربتات والمحتوى داخل `index.html`.
- يعمل بدون إنترنت بعد أول تحميل (الخطوط الخارجية اختيارية ولها بدائل نظامية).
- غلاف + مقدمة + الأحكام التمهيدية + الكتب الخمسة بموادها.
- تنقل كامل: السابق / التالي / الانتقال إلى رقم صفحة / شريط تقدم ذهبي.
- فهرس شامل: على الحاسوب شريط جانبي ثابت، وعلى الهاتف Drawer احترافي بزر فتح وإغلاق واضحين.
- بحث فوري في نص القانون + انتقال مباشر لأي مادة برقمها.
- روابط داخلية ذكية بين المواد المُشار إليها نصًا.
- توثيق الصفحة الحالية في الرابط (#m137) واستعادتها عند إعادة الفتح.
- متجاوب من 320px حتى الشاشات الكبيرة، بدون أي تمرير أفقي.
- بدون أخطاء Console، بدون مفاتيح API، بدون تتبع.
